# Данные

- `train/`, `valid/`, `test/` — исходные пользовательские файлы. Сохранены локально,
  не изменены, не включаются в новый исходный пакет/Docker.
- `external/holdout/` — 50 сохранённых внешних фотографий, эталоны и источники.
- `manifests/training.json` — состав расширенного обучения, без тяжёлого кеша.
- `sources/` — карточки и лицензии открытых источников.
- `cache/` — создаётся только командой `prepare-data`, игнорируется Git.

Эталонные данные не передаются нейросети при распознавании. Manifest evaluation
поддерживает поля `schema_version: 1`, `samples: [{id, image, expected, sha256?}]`.
Пути image должны быть относительными и находиться внутри каталога manifest.
